# HFLinkDocs — HFLink 官方文档

[HFLink 调试探针](https://github.com/LX050724/HFLink)（开源硬件）及其配套软件——HFLinkSDK 驱动与 HFLinkCLI 命令行工具——的官方用户文档。

**在线阅读**：<https://lx050724.github.io/HFLinkDocs/>

## 文档内容

- **快速开始**：探针环境准备、连接与首个调试会话
- **HFLinkCLI 使用指南**：`flash` / `gdb` / `rtt` 子命令及内嵌 Lua 脚本模式
- **API 参考**：HFLinkDriver 公开 C API，覆盖设备基础、Flash 下载、CMSIS-Pack 查询、RTT、HSS 高速采样、Semihosting 与统一错误码

## 获取文档

- **在线浏览**：访问 <https://lx050724.github.io/HFLinkDocs/>，随软件版本发布持续更新
- **离线文档**：随每个软件版本发布的完整 HTML 压缩包，可在无网络环境查阅
- **历史版本**：按版本号归档的过往版本文档
