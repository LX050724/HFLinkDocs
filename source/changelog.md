# 更新日志

记录 HFLinkSDK 及其配套工具（HFLinkCLI、HFLink_Flash 等图形界面工具）面向用户的功能与行为变化。文档随软件版本发布同步更新。

## 2026-09-04：Flash 下载与连接更新

- Flash 下载 API 调用完成后目标保持停机（halt），不再自动恢复运行，需要运行固件时请显式触发复位。
- `flash program` 连接阶段默认执行系统复位（`--reset` 默认值改为 `system`），提升较高 SWD 时钟频率下的烧录成功率。
- 移除 `flash program` 的 `--run` 选项，编程后恢复运行请改用 `--reset-after`。
- 修复较高 SWD 时钟频率下复位未完成即被误判完成导致的下载失败、目标意外启动与校验失败。
- 修复连接阶段所选复位类型未实际生效的问题。
- 提升与 HFLink 探针建立连接时的通信稳定性。
