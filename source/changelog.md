# 更新日志

记录 HFLinkSDK 及其配套工具（HFLinkCLI、HFLink_Flash 等图形界面工具）面向用户的功能与行为变化。文档随软件版本发布同步更新。

## 2026-09-06：Flash 下载与进度显示优化

- 预检查确认一致的扇区在校验阶段不再重复读取，重复烧录整体耗时进一步缩短。
- 内容为空白（与擦除值相同）的页不再重复编程，含大量空白区域的镜像下载更快。
- 图形界面工具中预检查作为独立阶段显示进度与耗时，下载速度按实际写入量统计。
- Flash 烧录范围按芯片包描述与算法实际支持范围共同界定，芯片选择界面同步只显示可用的 Flash 区域。

## 2026-09-05：Flash 下载提速与本地 Pack 安装

- Flash 下载自动跳过内容已一致或空白的扇区，重复烧录明显加快。
- 新增 `flash program --force-prog` 选项，可禁用跳过优化、强制擦写所有扇区。
- 烧录范围覆盖整个 Flash 区域时自动改用整片擦除，缩短擦除耗时。
- 优化 Turbo 下载的指令流水线，提升下载速度与稳定性。
- Classic 模式烧录时不再向终端输出冗余的诊断调试信息。
- CMSIS-Pack 管理工具新增本地导入功能，无需联网即可安装 `.pack` 固件包，版本冲突时会弹窗确认。

## 2026-09-04：Flash 下载与连接更新

- Flash 下载 API 调用完成后目标保持停机（halt），不再自动恢复运行，需要运行固件时请显式触发复位。
- `flash program` 连接阶段默认执行系统复位（`--reset` 默认值改为 `system`），提升较高 SWD 时钟频率下的烧录成功率。
- 移除 `flash program` 的 `--run` 选项，编程后恢复运行请改用 `--reset-after`。
- 修复较高 SWD 时钟频率下复位未完成即被误判完成导致的下载失败、目标意外启动与校验失败。
- 修复连接阶段所选复位类型未实际生效的问题。
- 提升与 HFLink 探针建立连接时的通信稳定性。
